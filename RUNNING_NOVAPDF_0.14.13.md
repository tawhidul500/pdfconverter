# Running NovaPDF 0.14.14 on Windows

1. Extract to a fresh folder.
2. Start Docker Desktop.
3. Run `RUN_NOVAPDF_ALL.cmd`.
4. Open PDF to Word.
5. Select `Preserve layout`.
6. Select `OCR` and choose English, Bangla, or English + Bangla.
7. Convert and open the DOCX in Microsoft Word.
8. Confirm the visible layout is unchanged and use Word Find to locate OCR text.
