# Running NovaPDF v0.14.14 on Windows

1. Extract the ZIP into a new folder, for example `C:\NovaPDF-v1414`.
2. Start Docker Desktop.
3. Double-click `RUN_NOVAPDF_ALL.cmd`.
4. Wait for converter, frontend, backend, migration, route, and E2E gates.
5. Open **PDF to Word**.
6. Select **Editable layout (Beta)**.
7. Enable OCR for scans or image-only regions. Select English, Bangla, or English + Bangla.
8. Convert and open the DOCX in Microsoft Word.

Use **Preserve layout** when pixel-level appearance matters more than direct editing. Use **Editable text** when paragraph reflow matters more than original page positioning.
