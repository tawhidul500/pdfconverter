# NovaPDF 0.4.7 Release Notes

This release standardises result downloads and clarifies workspace navigation.

## Highlights

- Split PDF now uses the same green success card and full-width dark download-button pattern as Merge and Organize.
- A reusable `WorkspaceResultCard` component is now the required result/download pattern for upcoming tools.
- Multi-output Split jobs keep individual downloads while presenting every download as a full-width consistent button.
- Clicking the NovaPDF rail logo closes the workspace, preserves the tool session in memory, and scrolls to the homepage.
- A horizontal divider now sits directly below the logo so it is visually separated from tool options.
