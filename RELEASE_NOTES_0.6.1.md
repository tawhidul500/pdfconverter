# Release Notes - NovaPDF 0.6.1

**Release:** JPG to PDF Live Preview Update  
**Date:** 19 July 2026

## Added

- Live PDF page preview for JPG to PDF settings
- A4, Letter, and Auto page-size changes appear immediately in the workspace
- Auto, Portrait, and Landscape orientation changes appear immediately
- None, Small, and Large margin changes update visible page spacing
- Fit Entire Image and Fill Page update the preview immediately
- Auto orientation preview labels the actual Portrait or Landscape result per image
- Final PDF generation uses the same sizing, orientation, margin, and fit calculations as the preview

## Defaults

- Page size: A4
- Orientation: Auto
- Margin: Small
- Image fit: Fit Entire Image
