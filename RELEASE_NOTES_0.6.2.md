# Release Notes - NovaPDF 0.6.2

**Release:** Cleaner Workspace Thumbnails  
**Date:** 19 July 2026

## Changed

- Removed visible file names from canvas thumbnails/cards across Merge, Organize, Compress, and JPG to PDF.
- Removed image dimensions and file sizes from JPG to PDF canvas thumbnails.
- Removed the rotation-degree badge from JPG to PDF canvas thumbnails.
- Removed the A4/Letter/Auto page-size and orientation label from JPG to PDF live thumbnails.
- Kept the output page number on Organize PDF cards so page order remains clear.
- Kept Split PDF page numbers and selection tick marks unchanged.

## Preserved

- The right-side panel still shows file names, dimensions, file sizes, page counts, and other detailed information.
- All processing, drag-and-drop, ordering, rotation, removal, zoom, output, and tool-transfer behavior remains unchanged.
- JPG to PDF live preview still visually reflects page size, orientation, margin, and Fit/Fill settings even though the text label is hidden.
