NovaPDF v0.14.15 source change summary

Release basis: supplied v0.14.14 source; no rebuild.

Core conversion changes:
- Native PDF text objects removed before fallback rendering.
- Rectangle-cell tables reconstructed as Word tables.
- New line-grid table detector for independent horizontal/vertical PDF paths.
- Aligned row/cell fills mapped into native Word table cells.
- Supported simple paths emitted as Word shapes.
- Embedded images emitted as anchored Word pictures.
- Reconstructed objects removed from fallback artwork to prevent duplication.
